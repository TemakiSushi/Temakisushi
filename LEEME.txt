CÓMO SUBIR A GITHUB + RENDER
1. Descomprimir el ZIP. Subir index.html y la carpeta assets al nivel raíz del repositorio.
2. En Render, crear New → Static Site y conectar el repositorio de GitHub.
3. Build Command: dejar vacío si lo permite, o escribir 'echo Sitio listo'.
4. Publish Directory: . (un punto).
5. Publicar. El enlace HTTPS que entrega Render mostrará el sitio.
